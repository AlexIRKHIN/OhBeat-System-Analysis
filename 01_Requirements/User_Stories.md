# 🎯 Vision, Роли и Пользовательские истории

## 1. Vision Statement
**OhBeat** — маркетплейс, где продюсеры продают биты, а артисты покупают на них лицензии с автоматической генерацией договора и мгновенной выдачей файлов. 

### 1.1. О продукте
**OhBeat (MVP-версия)** — Web-приложение с адаптивной версткой (интерфейс оптимизирован для десктопных и мобильных браузеров).

### 1.2. Бизнес-проблема
В настоящее время артисты и продюсеры договариваются о покупке инструменталов неструктурированно — через личные сообщения в социальных сетях. Это создает критические проблемы:
* **Для артистов:** Узкий выбор, отсутствие инструментов поиска по музыкальным характеристикам, высокий юридический риск нарушения авторских прав при релизе трека.
* **Для продюсеров (особенно начинающих):** Высокий порог входа к целевой аудитории и полное отсутствие гарантий оплаты после передачи исходных файлов.

### 1.3. Границы MVP
OhBeat выступает B2C/C2C гарантом сделки. Платформа автоматизирует полный цикл взаимодействия.
* **Входит в MVP:** Публикация битов с автоматической фоновой обработкой аудио, каталог с фильтрами и потоковым стримингом превью, корзина, оплата через ЮKassa, автоматическая генерация и подписание лицензионного договора (ПЭП), защищенная выдача файлов по временным ссылкам, раздел «Мои покупки», автоматическое сплитование выплат продюсерам.
* **Не входит в MVP:** Автоматические возвраты и споры (разбираются вручную через поддержку), возобновляемая загрузка сверхбольших файлов, мультивалютность, нативные мобильные приложения (iOS/Android), рекомендательные AI-системы.

## 2. Роли и Глоссарий

### 2.1. Пользовательские роли
Один аккаунт может быть одновременно Артистом и Продюсером (многие битмейкеры сами записывают треки), роли не являются взаимоисключающими.

| Роль | Описание | Основные действия |
| :--- | :--- | :--- |
| **Гость** | Неавторизованный посетитель | Ищет и фильтрует биты, слушает превью, регистрируется |
| **Артист** *(Покупатель)* | Исполнитель, ищущий легальный инструментал | Покупает лицензии, подписывает договор, скачивает исходники |
| **Продюсер** *(Продавец)* | Битмейкер, монетизирующий свои работы | Публикует биты, устанавливает цены, получает выплаты |
| **Администратор** | Сотрудник платформы | Управляет справочниками, читает Audit Log, разбирает инциденты |

### 2.2. Типы лицензий
| Код лицензии | Название в UI | Файлы покупателю | Правовая природа | Статус бита после продажи |
| :--- | :--- | :--- | :--- | :--- |
| `basic` | Basic Lease | MP3 320 кбит/с (без войстега) | Неисключительная лицензия | Остается в продаже |
| `premium` | Premium Lease | MP3 + WAV | Неисключительная лицензия | Остается в продаже |
| `trackout` | Trackout Lease | MP3 + WAV + ZIP со стемами | Неисключительная лицензия | Остается в продаже |
| `exclusive` | Exclusive | MP3 + WAV + ZIP со стемами | Исключительная лицензия | **Снимается с продажи навсегда** |

### 2.3. Термины предметной области
| Термин | Значение |
| :--- | :--- |
| **Бит** | Музыкальный инструментал, выставленный на продажу (содержит мастер WAV, стемы ZIP, обложку и метаданные). |
| **Превью** | Сжатый MP3 (128 кбит/с) с войстегом для ознакомительного прослушивания в каталоге. |
| **Войстег** | Голосовая аудиометка продюсера, циклично накладываемая на превью для защиты от кражи (Audio Watermark). |
| **Стемы** | Отдельные поканальные аудиодорожки бита (бас, мелодия, ударные), упакованные в ZIP-архив. |
| **Резерв** | Временная блокировка бита на 15 минут, пока покупатель оформляет эксклюзивные права. |
| **Presigned URL** | Временная криптографически подписанная ссылка, разрешающая прямой доступ к одному объекту S3 в обход бэкенда. |
| **Двухстадийный платеж** | Механизм эквайринга: средства сначала блокируются на карте (Hold), а списываются (Capture) только после системной валидации. |
| **ПЭП / OTP** | Простая электронная подпись (по 63-ФЗ РФ), подтверждаемая одноразовым OTP-кодом из SMS или Email. |

## 3. Пользовательские истории (User Stories)

### 3.1. Epic: Покупка и лицензирование (Артист)
| ID | User Story | Связь с требованиями |
| :--- | :--- | :--- |
| **US-A1** | Как Артист, я хочу прослушать превью бита целиком во встроенном плеере и перематывать его, чтобы оценить структуру и звучание до покупки. | [RFC: Стриминг аудиопревью](../02_Architecture/RFC_Audio_Streaming.md) |
| **US-A2** | Как Артист, я хочу фильтровать каталог по жанру, BPM, тональности и цене, чтобы быстро находить релевантный материал. | [REST API: Каталог](../03_API_and_Integrations/REST_API_Contracts.md) |
| **US-A3** | Как Артист, я хочу добавить бит в корзину с выбранным типом лицензии и оплатить заказ картой, чтобы получить доступ к файлам. | [FR: Корзина и Заказы](FR_NFR.md) |
| **US-A4** | Как Артист, я хочу автоматически получить подписанный лицензионный договор (ПЭП), чтобы юридически обезопасить свой релиз. | [RFC: ЭЦП по 63-ФЗ](../02_Architecture/RFC_Digital_Signature.md) |
| **US-A5** | Как Артист, я хочу в любой момент заново скачивать купленные файлы из раздела «Мои покупки», чтобы не потерять их при истечении срока временной ссылки. | [FR: Выдача файлов (Fulfillment)](FR_NFR.md) |

### 3.2. Epic: Управление контентом (Продюсер)
| ID | User Story | Связь с требованиями |
| :--- | :--- | :--- |
| **US-P1** | Как Продюсер, я хочу единовременно загрузить мастер WAV, ZIP со стемами и обложку, чтобы система сама выдавала покупателю нужные форматы в зависимости от лицензии. | [FR: Публикация бита](FR_NFR.md) |
| **US-P2** | Как Продюсер, я хочу указать жанры, BPM, тональность и описание, чтобы мой бит корректно индексировался в поиске платформы. | [FR: Метаданные](FR_NFR.md) |
| **US-P3** | Как Продюсер, я хочу задать отдельную цену для каждого из 4 типов лицензий, чтобы гибко управлять своим доходом. | [REST API: Управление ценами](../03_API_and_Integrations/REST_API_Contracts.md) |
| **US-P4** | Как Продюсер, я хочу видеть статус фоновой обработки бита (успех или отклонение с причиной), чтобы иметь возможность исправить проблемный файл (например, битый архив). | [FR: Асинхронная обработка (Worker)](FR_NFR.md) |
| **US-P5** | Как Продюсер, я хочу иметь публичную страницу профиля с витриной битов и получать автоматические выплаты за продажи, чтобы монетизировать свое творчество. | [FR: Выплаты и Сплитование](FR_NFR.md) |
